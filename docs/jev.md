# Jev 个股判断

在持仓或自选列表打开个股详情，切到 **Jev 判断**。页面读取配置状态和最近记录；只有点击「生成 Jev 判断」才调用 TypeSafe API。

一次手动运行覆盖：

- 当前技术趋势：偏强、中性、偏弱或数据不足。
- 当前波动和下行风险：低、中、高或数据不足。
- 未来方向：可选 1、3、5 个后续实际交易日，上涨、横盘、下跌或数据不足。
- AI 报告证据复核：证据支持、部分支持、证据反驳或证据不足。没有同市场同标的的可识别报告时跳过此项。

Jev 不生成自然语言解释。页面展示它返回的分类、完整选项概率和模型置信度，不把这些数值称为交易胜率。

## 配置

从 [TypeSafe 控制台](https://console.typesafe.ai) 获取有访问权限的密钥，在服务端 `.env` 中设置：

```dotenv
TYPESAFE_API_KEY=你的密钥
JEV_MODEL=jev-latest
JEV_TIMEOUT_SECONDS=30
```

密钥不进入前端、判断记录或 Git。Docker 用户须通过 `--env-file` 或 `environment` 将变量传给容器，然后重建容器；仅编辑宿主机文件不会更新已有容器环境。源码运行时可用仓库原有启动方法。

Jev 是独立的 System One 接口，不能通过修改 OpenAI 兼容服务商中的模型名称完成配置。当前使用固定官方端点 `https://api.typesafe.ai/v1/systemone`，支持现有 `HTTP_PROXY` / `HTTPS_PROXY` 环境以及 `http_proxy` 设置。

改造后的源码需要自行构建镜像，原作者发布的镜像不包含本分支功能：

```bash
docker build -t panwatch-jev:local .
docker run -d --name panwatch-jev \
  -p 127.0.0.1:8000:8000 \
  --env-file .env \
  -v panwatch_jev_data:/app/data \
  panwatch-jev:local
```

以上示例从本机访问。升级既有实例时，先备份数据库并使用原实例的数据卷；不要让两个容器同时写同一份数据库。

## 数据与预测定义

- 当前版本使用已有行情采集器的日 K 线和技术指标，不包含实时盘口、新闻或基本面证据。每次手动判断强制重新取数，避免收盘前缓存被误当作收盘数据；刷新失败时不回退旧缓存。
- 按市场时区过滤未完成日线，通常等常规收盘后 15 分钟再纳入当日。港股使用收市竞价上界 16:10，再加 15 分钟；美股使用纽约时区并处理夏令时。提前收市仍等常规时间，属于保守处理。
- 至少需要 60 根有效已完成日线；拒绝超过 7 个自然日的旧数据。节假日、停牌、提前收市及复权质量仍需结合来源核对，页面显示相应数据提示。
- 指标、风险数值和参考收盘价都由 Python 基于同一批过滤后的日线计算。
- 若 `as_of` 为 T，周期为 N，则预测比较 T+N 的实际交易日收盘价与 T 收盘价的**累计收益**；不把自然日当交易日，也不把逐日预测相加。
- 默认横盘阈值为 ±1%，可选 0.1%—10%。累计收益严格大于正阈值为上涨，严格小于负阈值为下跌，包含边界的其余区间为横盘。

报告复核与方向预测分开调用，避免原 AI 报告影响方向判断。复核仅回答报告论断是否得到本次提供证据的支持，不等同于历史时点审计或验证预测正确率。没有新闻、财报证据时，相关论断不能被当作已验证事实。

已有报告必须带有明确的市场元数据。不能识别市场的旧报告会跳过，不根据股票代码猜测；新生成的 TradingAgents 报告会保存标的和市场信息。过长报告会限制长度并显示截断提示。

## 历史与错误处理

每次成功运行追加一条 `jev_judgments` 记录，按标的和市场隔离；同日再次运行不覆盖旧记录。数据库保存输入日线、指标、问题版本、复核来源和模型输出，便于之后评估。本版提供历史查看，不自动计算回测胜率或执行交易。

未配置密钥、数据不足、过期数据、上游错误或无效概率会返回明确错误，不伪造判断。明确的 429/529 限流响应最多重试一次；网络超时不自动重试，以免重复消费。开启复核时会多一次 API 请求，费用由 TypeSafe 账户产生。

## 接口

全部接口需要现有 PanWatch 登录认证：

| 方法与路径 | 用途 |
| --- | --- |
| `GET /api/jev/status` | 只返回是否配置及模型名 |
| `POST /api/jev/judgments` | 手动生成并保存判断 |
| `GET /api/jev/judgments?symbol=600519&market=CN&limit=10` | 查询同标的同市场历史 |

请求示例：

```json
{"symbol":"600519","market":"CN","horizon":3,"flat_threshold_pct":1.0}
```

可选 `analysis_id` 用于指定复核报告；仍需满足同标的、同市场约束。响应沿用 PanWatch 的统一 API 包装。

参考：[TypeSafe API](https://docs.typesafe.ai/api)、[置信度语义](https://docs.typesafe.ai/confidence)、[Jev 已知限制](https://docs.typesafe.ai/model-jaggedness/jev-1.13)。
